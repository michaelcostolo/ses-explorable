The Corridor of Complexity

A small explorable model for state-expanding systems: as the number of components grows, feasible novelty survives only inside a moving band of constraint.

In this toy version of the SES model, the curve is defined by the constant-feasibility relation c(n) = b ε1/(g n). The original form is c(n) = b ε1/n. Here neff = g n, so g scales the effective combinatorial burden without changing the underlying model.

Reading the Curve

The vertical axis is c, the effective base of feasible growth. The horizontal axis is logarithmic in n, the number of combinable components, so the same figure can span small systems and very large state spaces. With as the scale factor and as the scaling factor for effective burden, each threshold value of ε produces one curve: the value of c needed for the feasible fraction to sit at that threshold. Feasible and Infeasible Regions

Below the corridor, feasibility has collapsed faster than the state space has expanded. Novelty may still exist, but it is too sparse to form connected paths of reachable configurations. Above the corridor, feasible combinations are abundant; exploration is easy, but the space is not yet sharply differentiated by constraint.

Changing the thresholds changes what counts as reachable. A looser upper threshold widens the permitted band, while a stricter lower threshold pushes the lower boundary downward. The reachable space therefore is not only a matter of system size; it is also a matter of where the system's constraints place the boundary between viable and nonviable combinations.

The orange curve uses the geometric midpoint between the two thresholds, so it moves with the corridor while remaining centered in feasibility-ratio space. When enabled, the purple dashed overlay shows a finite-difference estimate of the midpoint curve's slope with respect to log(n).
